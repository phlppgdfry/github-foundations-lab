# Lab 01 - Branches en commits

## Doel

Een kleine wijziging veilig voorbereiden buiten `main` en met leesbare commits vastleggen.

## Checklist

- [ ] Maak een issue met de Lab task-template.
- [ ] Maak de branch `lab/01-branches`.
- [ ] Pas [submissions/profile.md](submissions/profile.md) aan.
- [ ] Maak minstens twee inhoudelijke commits.
- [ ] Bekijk `git status`, `git log --oneline` en `git diff` in VS Code of de terminal.
- [ ] Push de branch zodra de remote bestaat.
- [ ] Open een pull request en link het issue.

## Reflectie

Beschrijf in de PR het verschil tussen working directory, staging area en commit history.
