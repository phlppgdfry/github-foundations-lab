# Lab 05 - Discussions, tags en releases

## Checklist

- [ ] Activeer Discussions in de repository-instellingen.
- [ ] Start een Discussion waarin je een studievraag stelt.
- [ ] Voeg een antwoord of samenvatting toe en markeer het als antwoord waar mogelijk.
- [ ] Maak een annotated tag `v0.1.0`.
- [ ] Publiceer een GitHub release met notes die uitleggen wat er in de eerste versie zit.

## Reflectie

Leg uit wanneer je een issue, Discussion en release note zou gebruiken.
