# Lab 07 - Codespaces en Actions

## Checklist

- [ ] Start een Codespace vanuit de repository op GitHub.com.
- [ ] Voer `bash scripts/verify.sh` uit in de Codespace.
- [ ] Maak een kleine documentatiewijziging en commit die vanuit de Codespace.
- [ ] Lees `.github/workflows/repository-check.yml` regel voor regel.
- [ ] Bekijk de run in het Actions-tabblad na een push of PR.
- [ ] Leg uit wat de `GITHUB_TOKEN`-permissions in de workflow beperken.
