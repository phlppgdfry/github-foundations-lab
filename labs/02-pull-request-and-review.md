# Lab 02 - Pull request en review

## Checklist

- [ ] Maak een wijziging in een nieuwe branch.
- [ ] Vul de PR-template volledig in.
- [ ] Link de PR aan een issue met `Closes #nummer`.
- [ ] Voeg een inline reviewcommentaar toe, of vraag een collaborator om een echte review.
- [ ] Reageer op de feedback met een commit of gemotiveerde toelichting.
- [ ] Controleer dat de Action-check geslaagd is voordat je merged.

## Reflectie

Leg het verschil uit tussen een commentaar op een PR en een approval/request changes-review.
