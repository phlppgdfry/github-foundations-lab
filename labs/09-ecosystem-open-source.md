# Lab 09 - GitHub-ecosysteem en open source

## Checklist

- [ ] Bekijk een openbare open-source repository en identificeer README, license, contributing guide, issues en releases.
- [ ] Lees de beschrijvingen van Gists, Wikis en GitHub Pages. Kies één realistisch gebruiksscenario per feature.
- [ ] Bezoek GitHub Marketplace en noteer waarvoor een Action of App kan dienen.
- [ ] Volg een relevante organisatie of gebruiker en controleer je notification-instellingen.
- [ ] Leg het verschil tussen een fork en een template uit met [key-distinctions.md](../docs/key-distinctions.md).
- [ ] Schrijf kort wat InnerSource betekent en wanneer GitHub Sponsors relevant is.

## Reflectie
