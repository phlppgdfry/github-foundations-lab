# Lab 04 - Issues, milestones en Projects

## Checklist

- [ ] Maak een issue voor een feature, bug en documentatietaak.
- [ ] Geef elk issue een passend label.
- [ ] Maak de milestone `GH-900 preparation`.
- [ ] Maak een GitHub Project met Todo, In progress en Done.
- [ ] Voeg elk issue toe aan de juiste status.
- [ ] Sluit één issue met een pull request.

## Reflectie

Wanneer groepeer je werk met labels, milestones en Projects? Geef voor elk een ander doel.
