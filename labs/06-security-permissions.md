# Lab 06 - Security en permissions

## Checklist

- [ ] Lees de GitHub Docs over repository roles.
- [ ] Noteer welk minimum access-niveau een issue-triager en codecontributor nodig hebben.

- [ ] Lees `SECURITY.md` en leg uit waarom meldingen niet als publiek issue horen.
