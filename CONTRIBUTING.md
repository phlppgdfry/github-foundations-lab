# Contributing

Gebruik deze eenvoudige workflow voor elk lab.

1. Kies of maak een issue.
2. Maak een branch vanaf `main`: `lab/01-branches`.
3. Maak kleine, duidelijke commits, bijvoorbeeld `docs: complete lab 01 notes`.
4. Open een pull request naar `main`.
5. Vul de PR-template in, vraag een review en los feedback op.
6. Merge pas wanneer de repository-check geslaagd is.

## Commitstijl

Gebruik een kort type-prefix: `docs:`, `feat:`, `fix:`, `test:` of `chore:`. Dit is geen vereiste van GH-900, maar maakt de geschiedenis leesbaar.

## Veiligheid

Plaats nooit tokens, wachtwoorden of private keys in commits. Gebruik GitHub Secrets voor gevoelige waarden en meld kwetsbaarheden via [SECURITY.md](SECURITY.md).
