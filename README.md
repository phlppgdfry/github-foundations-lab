# GitHub Foundations Lab (GH-900)

Een praktische leerrepo voor de **GitHub Foundations**-certificering. Je leert elk onderwerp door het daadwerkelijk in GitHub te gebruiken en bewaart je voortgang als bewijs.

> Dit is een studielab, geen verzameling echte examenvragen. Raadpleeg voor de actuele examendetails altijd de [officiële GitHub-certificeringspagina](https://learn.github.com/certification/GHF).

## Start hier

1. Open deze map in VS Code: `code github-foundations-lab`.
2. Lees [docs/learning-path.md](docs/learning-path.md).
3. Open een issue met de template **Lab task**.
4. Maak voor elk lab een eigen branch en pull request.
5. Vink je voortgang af in [study/exam-objectives.md](study/exam-objectives.md).

## Wat je oefent

| Onderwerp | Bewijs in deze repo |
| --- | --- |
| Git-basis | branches, commits, merges, tags en een bewust merge conflict |
| Repositories | README, license, `.gitignore`, releases en repository-instellingen |
| Samenwerken | issues, labels, milestones, projects, pull requests en reviews |
| GitHub-producten | Discussions, Codespaces, Actions, notifications en profile features |
| Veilig werken | minimaal-rechten-principe, secrets en security reporting |

## Definitie van examen-klaar

Je bent klaar om een GH-900-examen te plannen wanneer je alle onderstaande punten kunt afvinken:

- [ ] Alle zeven labs hebben een issue, branch en PR of ander zichtbaar bewijs.
- [ ] Alle doelen in [study/exam-objectives.md](study/exam-objectives.md) zijn met eigen woorden uitgelegd én toegepast.
- [ ] Je kunt de scenario's in [study/self-checks.md](study/self-checks.md) zonder hulp beantwoorden.
- [ ] Je hebt je zwakke onderwerpen herhaald tot ze als beheerst gemarkeerd zijn.
- [ ] Je hebt een externe oefentoets gemaakt en herhaalt alleen nog onderwerpen waarop je fouten maakte.

## Kwaliteitscheck

De workflow in `.github/workflows/repository-check.yml` voert bij elke push en pull request `scripts/verify.sh` uit. Die controleert of de essentiële community- en studiedocumenten aanwezig zijn.
