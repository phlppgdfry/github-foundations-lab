# GitHub-features om bewust te gebruiken

| Feature | Praktijkopdracht |
| --- | --- |
| Issues | Maak een issue met labels, assignee en milestone. |
| Pull requests | Link een PR aan een issue en vraag een review. |
| Projects | Zet het issue op een board met de status Todo, In progress en Done. |
| Discussions | Start een vraag of kennisdeling en markeer een antwoord. |
| Releases | Maak een tag en publiceer een release met release notes. |
| Notifications | Wijzig je watch-instellingen en leg uit welke meldingen je ontvangt. |
| Codespaces | Start de repo en maak een kleine documentatiewijziging. |
| Actions | Lees de workflow en laat een check runnen na een pull request. |
