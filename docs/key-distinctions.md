# Belangrijke verschillen om zonder twijfel te kennen

| Begrippen | Kort onderscheid |
| --- | --- |
| Git vs. GitHub | Git is het gedistribueerde versiebeheersysteem; GitHub is een platform rond Git voor hosting, samenwerking en extra producten. |
| Issue vs. Discussion vs. PR | Een issue volgt werk of een probleem; een Discussion is voor open gesprek/kennisdeling; een PR stelt een wijziging ter beoordeling voor. |
| GitHub Desktop vs. GitHub Mobile | Desktop is een grafische Git-client voor lokaal werk; Mobile is voor notificaties, reviews en lichte repository-interactie onderweg. |
| Codespaces vs. github.dev | Codespaces is een cloudontwikkelomgeving met compute en terminal; github.dev is een lichte browsereditor zonder volledige runtime. |
| Fork vs. template | Een fork kopieert een bestaand project met relatie tot de bron; een template start een nieuw project zonder die forkrelatie. |
| Public vs. private vs. internal | Public is zichtbaar voor iedereen; private beperkt toegang; internal is voor leden van een enterprise. |
| 2FA vs. passkey | 2FA voegt een tweede factor toe; een passkey gebruikt phishingbestendige apparaatcryptografie om aan te melden. |
| Individual vs. Business vs. Enterprise Copilot | Individual is voor persoonlijk gebruik; Business voegt organisatiebeheer toe; Enterprise integreert breder met enterprise-context en policies. |

Controleer voor details altijd de actuele GitHub Docs: productmogelijkheden en plannen kunnen veranderen.
