# Zelfchecks

Dit zijn zelfgeschreven praktijkscenario's, geen echte examenvragen.

1. Een bijdrage moet worden nagekeken voor ze in `main` komt. Welke GitHub-flow gebruik je en waarom?
2. Je wilt werk opdelen zonder dat een branch vroegtijdig gemerged wordt. Welke combinatie van issue, branch en pull request kies je?
3. Een token belandt per ongeluk in een commit. Welke onmiddellijke acties neem je?
4. Iemand moet issues triageren, maar mag geen code pushen. Welke toegang past het best?
5. Wanneer gebruik je een GitHub Project en wanneer volstaat een milestone?

Beantwoord elke vraag in je eigen woorden. Controleer vervolgens je antwoord met GitHub Docs en noteer een link in je PR.
