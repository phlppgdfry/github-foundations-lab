# GH-900 - examendoelen en bewijs

Werk deze lijst af met de actuele [officiële examengids](https://learn.github.com/certification/GHF). Zet na ieder afgerond onderwerp een link naar je issue, PR, discussie, release of eigen notitie. De percentages tonen de relatieve examengewichten.

## 1. Git en GitHub-basis (25-30%)

- [ ] Ik kan uitleggen waarom versiebeheer waardevol is.
- [ ] Ik ken het verschil tussen Git en GitHub.
- [ ] Ik kan repository, commit, branch, merge, remote en tag uitleggen en gebruiken.
- [ ] Ik kan GitHub Flow uitleggen en toepassen via een branch en pull request.
- [ ] Ik kan Markdown gebruiken voor een issue en PR.
- [ ] Ik kan accounts, organisaties en GitHub Enterprise van elkaar onderscheiden.
- [ ] Ik weet wanneer GitHub Desktop of GitHub Mobile nuttig is.

Bewijs: Labs 01-03 en 08.

## 2. Repositories (10-15%)

- [ ] Ik ken de rol van README, LICENSE, CONTRIBUTING, CODEOWNERS en SECURITY.
- [ ] Ik kan een repository maken, structureren en onderhouden met templates en branches.
- [ ] Ik kan bestanden toevoegen, wijzigen en organiseren.
- [ ] Ik weet waar repository insights, stars, feature previews, metrics en dependency insights voor dienen.
- [ ] Ik kan onderhouds- en samenwerkingsafspraken uitleggen.

Bewijs: startstructuur, Lab 01 en Lab 08.

## 3. Samenwerken (10-15%)

- [ ] Ik kies bewust tussen issue, pull request en Discussion.
- [ ] Ik kan een PR aan een issue linken en templates, filters, assignees en labels gebruiken.
- [ ] Ik kan notifications beheren.
- [ ] Ik ken het doel van Gists, Wiki en GitHub Pages.

Bewijs: Labs 02, 04, 05 en 09.

## 4. Moderne development practices (10-15%)

- [ ] Ik ken het doel en de basisonderdelen van GitHub Actions.
- [ ] Ik kan de belangrijkste mogelijkheden van Copilot beschrijven, inclusief agents, Agent Mode en multi-model support.
- [ ] Ik kan Copilot Individual, Business en Enterprise op hoofdlijnen onderscheiden.
- [ ] Ik kan Codespaces, dev containers en hun gebruik uitleggen.
- [ ] Ik ken het verschil tussen github.dev en Codespaces.

Bewijs: Labs 07 en 10.

## 5. Projectmanagement (5-10%)

- [ ] Ik ken GitHub Projects-layouts en kan een Project configureren.
- [ ] Ik kan labels, milestones, workflows, saved replies en assignees toepassen.
- [ ] Ik weet waarvoor project insights dienen.

Bewijs: Lab 04.

## 6. Privacy, security en administration (10-15%)

- [ ] Ik kan 2FA en passkeys als accountbescherming uitleggen.
- [ ] Ik ken repository- en organisatierollen en permissions.
- [ ] Ik weet waarvoor Enterprise Managed Users en organisatiebrede Copilot-policies dienen.
- [ ] Ik kan repository visibility, privacy en branch protection uitleggen.
- [ ] Ik ken het doel van teams, organisatie-instellingen en rollen.

Bewijs: Labs 06 en 08.

## 7. GitHub-community (5-10%)

- [ ] Ik kan de waarde van open source en GitHub Sponsors uitleggen.
- [ ] Ik weet hoe GitHub open-sourceprojecten ondersteunt.
- [ ] Ik kan gebruikers en organisaties volgen en de GitHub Marketplace plaatsen.
- [ ] Ik kan InnerSource uitleggen.
- [ ] Ik weet wanneer forks, templates en discoverable repositories nuttig zijn.

Bewijs: Lab 09.
